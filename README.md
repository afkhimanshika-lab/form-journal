# Experiment 6 – Responsive Blog Website

## Aim

To build a responsive blog website using Bootstrap and CSS
media queries so that the website adapts to different screen sizes.

## Project Name

FORM — Digital Journal

## Description

FORM is an editorial-style blog website containing articles
about architecture, design, culture, technology and lifestyle.

The website uses a minimal visual design with large typography,
large visual sections and responsive layouts.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Google Fonts

## Bootstrap Features Used

- Responsive Navbar
- Bootstrap Container
- Bootstrap Grid
- Bootstrap Rows
- Bootstrap Columns
- Responsive ordering classes
- Bootstrap JavaScript

## CSS Features

- Flexbox
- Responsive typography
- Hover effects
- Smooth scrolling
- Custom layouts
- CSS media queries

## Media Queries

### Tablet

The website uses:

@media (max-width: 991px)

This changes image sizes, typography and spacing for tablet
and smaller laptop screens.

### Mobile

The website uses:

@media (max-width: 576px)

This changes the website to a mobile-friendly layout and
adjusts:

- Navigation
- Typography
- Images
- Spacing
- Story layouts
- Footer

## Website Sections

5. Design story

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Run the file using a browser or Live Server.
4. Resize the browser window to test responsiveness.

## Result

A responsive editorial blog website was successfully developed
using Bootstrap and CSS media queries. The website adapts its
layout, typography, navigation and content for desktop, tablet
and mobile screen sizes.
